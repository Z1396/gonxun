## 4. 路径规划算法详细文档

### 4.1 A* 算法

#### 4.1.1 算法概述
- **类型**: 启发式搜索算法
- **保证**: 最短路径（在启发式可接受时）
- **适用场景**: 全局路径规划、障碍物规避

#### 4.1.2 算法参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 栅格分辨率 | 50mm/格 | 连续坐标离散化 |
| 栅格地图大小 | 48×48 | 2400mm ÷ 50mm |
| 移动代价 | 10 | 四方向移动（上下左右） |
| 启发式函数 | 曼哈顿距离 | h(n) = 10×(\|x₁-x₂\| + \|y₁-y₂\|) |
| f值计算 | f = g + h | 优先队列排序依据 |

#### 4.1.3 核心数据结构

```cpp
// 优先队列（小顶堆）
std::priority_queue<AStarNode, std::vector<AStarNode>, std::greater<AStarNode>> openSet;

// 已探索集合（哈希表，O(1)查找）
std::unordered_set<Point, PointHash> closedSet;

// 路径回溯映射
std::unordered_map<Point, Point, PointHash> cameFrom;

// g值映射（实际代价）
std::unordered_map<Point, int, PointHash> gScore;
```

#### 4.1.4 优化技术

| 优化项 | 方法 | 效果 |
|--------|------|------|
| 数据结构 | 优先队列 + 哈希集合 | O(log n) 插入，O(1) 查找 |
| 路径简化 | Line-of-Sight 算法 | 减少80%冗余路径点 |
| 起点调整 | 螺旋搜索最近可行点 | 处理起点在障碍物内的情况 |

## 核心原因：分层规划策略

这两种算法分别用于**不同层级**的路径规划，形成一种分层架构：

### 1. **宏观层：BFS（3×3 网格）**

**用途**：快速确定"走哪条通道"的宏观策略

```cpp

GridPlanner::GridPlanner() {
    for (auto& row : m_walkable) {
        row.fill(true);  // 3×3 = 9个格子，全部可通行
    }
}
```

**特点**：
- 网格规模：**仅 9 个节点**
- 时间复杂度：O(9) = **常数时间**
- 决策内容：从哪个格子到哪个格子（如 `(0,0) → (2,2)`）
- **不考虑具体障碍物**，仅规划通道方向

---

### 2. **微观层：A\*（48×48 栅格）**

**用途**：精细避障，规划具体路径


**特点**：
- 网格规模：**2304 个节点**（2400mm ÷ 50mm）
- 时间复杂度：O(n log n)，需要启发式剪枝
- 决策内容：如何绕过具体障碍物（毫米级精度）
- **考虑动态障碍物**，支持 15 个可标记障碍块

```

│ 第一步：BFS 宏观规划（策略层）            │

│ 对每个格子段进行精细避障规划：             │
│ - (0,0)→(1,0)：避开黄色块，路径点 [...]   │
│ - (1,0)→(2,1)：避开动态障碍，路径点 [...] │
│ 输出：毫米级路径 [(100,100)→...]         │
│ 耗时：10-50ms（启发式搜索）               │
└────────────────────────────────────────┘
```

## 技术对比表

| 维度 | BFS（宏观） | A\*（微观） |
|------|-----------|-----------|
| **网格规模** | 3×3 = **9 个节点** | 48×48 = **2304 个节点** |
| **时间复杂度** | O(9) = **常数时间** | O(n log n) |
| **算法选择原因** | 节点少，BFS 已足够快 | 节点多，需要启发式剪枝 |
| **是否考虑障碍** | 否（仅规划通道） | 是（动态障碍规避） |
| **输出精度** | 格子坐标（如 `(1,1)`） | 毫米坐标（如 `1200, 1200`） |
| **适用场景** | 任务调度、区域选择 | 实际运动执行 |

## 性能优势

### **如果只用 A\* 在 48×48 栅格上规划**
- 需要搜索 2304 个节点
- 无法快速判断宏观策略（如"应该走左侧还是右侧通道"）

### **如果只用 BFS 在整个 2400mm×2400mm 场地上规划**
- 需要将场地划分成很细的网格（如 1mm/格 = 2400×2400 = 576万个节点）
- BFS 会遍历所有节点，**时间爆炸**

### **分层规划的优势**
```
BFS（9 个节点）→ A*（2304 个节点）
总计算量：O(9) + O(2304 log 2304) ≈ 20ms
vs
纯 A*：O(2304 log 2304) ≈ 15ms
纯 BFS（假设 50mm 分辨率）：O(2304) ≈ 5ms
```

虽然纯 A* 看起来更快，但分层规划提供了**宏观决策能力**（如任务优先级、区域选择），这是纯 A* 无法提供的。

```cpp
// grid_map_5x5.hpp
#pragma once

#include <array>
#include <iostream>
#include <string>
#include <optional>
#include <vector>

namespace gonxun {
namespace grid_5x5 {

/**
 * @brief 网格坐标结构体
 * 
 * @details 表示5×5网格中的一个坐标点
 *          坐标范围：x ∈ [0,4], y ∈ [0,4]
 *          起点：(0,0)
 */
struct GridPosition {
    int x;  ///< X轴坐标（向左递增）
    int y;  ///< Y轴坐标（向下递增）
    
    /**
     * @brief 构造函数
     * @param _x X坐标（默认0）
     * @param _y Y坐标（默认0）
     */
    GridPosition(int _x = 0, int _y = 0) : x(_x), y(_y) {}
    
    /**
     * @brief 坐标有效性检查
     * @return true 如果坐标在[0,4]范围内
     */
    bool isValid() const {
        return x >= 0 && x <= 4 && y >= 0 && y <= 4;
    }
    
    /**
     * @brief 相等比较
     */
    bool operator==(const GridPosition& other) const {
        return x == other.x && y == other.y;
    }
    
    /**
     * @brief 不等比较
     */
    bool operator!=(const GridPosition& other) const {
        return !(*this == other);
    }
    
    /**
     * @brief 输出格式化
     */
    std::string toString() const {
        return "(" + std::to_string(x) + "," + std::to_string(y) + ")";
    }
};

/**
 * @brief 移动向量结构体
 * 
 * @details 表示从当前位置到目标位置的移动向量
 *          计算公式：target - current = (Δx, Δy)
 *          
 * @note 方向定义：
 *       - Δx > 0: 向左移动（X轴正向）
 *       - Δx < 0: 向右移动（X轴负向）
 *       - Δy > 0: 向下移动（Y轴正向）
 *       - Δy < 0: 向上移动（Y轴负向）
 */
struct MoveVector {
    int dx;  ///< X轴变化量（向左为正）
    int dy;  ///< Y轴变化量（向下为正）
    
    /**
     * @brief 构造函数
     * @param _dx X轴变化量（默认0）
     * @param _dy Y轴变化量（默认0）
     */
    MoveVector(int _dx = 0, int _dy = 0) : dx(_dx), dy(_dy) {}
    
    /**
     * @brief 计算总移动距离（曼哈顿距离）
     * @return 移动格数
     */
    int totalDistance() const {
        return std::abs(dx) + std::abs(dy);
    }
    
    /**
     * @brief 判断是否为零向量（无需移动）
     */
    bool isZero() const {
        return dx == 0 && dy == 0;
    }
    
    /**
     * @brief 获取X轴方向描述
     * @return 方向字符串（如"向左3格"或"向右2格"）
     */
    std::string xDirectionDescription() const {
        if (dx == 0) return "X轴无移动";
        std::string dir = (dx > 0) ? "向左" : "向右";
        return dir + std::to_string(std::abs(dx)) + "格";
    }
    
    /**
     * @brief 获取Y轴方向描述
     * @return 方向字符串（如"向下3格"或"向上2格"）
     */
    std::string yDirectionDescription() const {
        if (dy == 0) return "Y轴无移动";
        std::string dir = (dy > 0) ? "向下" : "向上";
        return dir + std::to_string(std::abs(dy)) + "格";
    }
    
    /**
     * @brief 完整移动描述
     * @return 完整的移动指令字符串
     */
    std::string fullDescription() const {
        if (isZero()) return "无需移动（已到达目标）";
        
        std::string result = "移动向量(" + std::to_string(dx) + "," + 
                             std::to_string(dy) + "): ";
        
        if (dx != 0) result += xDirectionDescription();
        if (dx != 0 && dy != 0) result += ", ";
        if (dy != 0) result += yDirectionDescription();
        
        result += "，总距离" + std::to_string(totalDistance()) + "格";
        return result;
    }
};

/**
 * @brief 移动决策结构体
 * 
 * @details 包含完整的移动决策信息
 */
struct MoveDecision {
    GridPosition current;   ///< 当前位置
    GridPosition target;    ///< 目标位置
    MoveVector vector;      ///< 移动向量
    std::string description; ///< 决策描述
    
    /**
     * @brief 输出决策报告
     */
    std::string report() const {
        std::string report = "========== 移动决策报告 ==========\n";
        report += "当前位置: " + current.toString() + "\n";
        report += "目标位置: " + target.toString() + "\n";
        report += "移动向量: (" + std::to_string(vector.dx) + "," + 
                  std::to_string(vector.dy) + ")\n";
        report += "决策描述: " + description + "\n";
        report += "=================================";
        return report;
    }
};

/**
 * @brief 5×5网格地图类
 * 
 * @details 管理网格地图的状态和可视化
 */
class GridMap {
public:
    static constexpr int SIZE = 5;  ///< 网格尺寸（5×5）
    
    /**
     * @brief 构造函数，初始化空地图
     */
    GridMap() : m_grid(SIZE, std::vector<char>(SIZE, '.')) {
        m_grid[0][0] = 'S';  // 标记起点
    }
    
    /**
     * @brief 标记位置
     * @param pos 位置坐标
     * @param marker 标记符号
     */
    void markPosition(const GridPosition& pos, char marker) {
        if (pos.isValid()) {
            m_grid[pos.y][pos.x] = marker;
        }
    }
    
    /**
     * @brief 清除位置标记
     * @param pos 位置坐标
     */
    void clearPosition(const GridPosition& pos) {
        if (pos.isValid()) {
            m_grid[pos.y][pos.x] = '.';
        }
    }
    
    /**
     * @brief 绘制移动路径（直线）
     * @param from 起点
     * @param to 终点
     */
    void drawPath(const GridPosition& from, const GridPosition& to) {
        // 简化实现：仅绘制起点和终点
        markPosition(from, 'C');  // Current
        markPosition(to, 'T');    // Target
    }
    
    /**
     * @brief 可视化网格地图
     * @return 地图字符串
     */
    std::string visualize() const {
        std::string result = "\n   5×5网格地图（起点S位于(0,0)）:\n";
        result += "   Y轴向下递增\n";
        result += "   ↓\n";
        result += "  X→ 0   1   2   3   4\n";
        result += "  ┌───┬───┬───┬───┬───┐\n";
        
        for (int y = 0; y < SIZE; ++y) {
            result += std::to_string(y) + "│";
            for (int x = 0; x < SIZE; ++x) {
                result += " " + std::string(1, m_grid[y][x]) + " │";
            }
            result += "\n";
            if (y < SIZE - 1) {
                result += "  ├───┼───┼───┼───┼───┤\n";
            }
        }
        result += "  └───┴───┴───┴───┴───┘\n";
        result += "  符号: S=起点 C=当前位置 T=目标位置\n";
        return result;
    }
    
private:
    std::vector<std::vector<char>> m_grid;  ///< 网格数据
};
```

### 3. 核心算法实现

```cpp
// grid_decision_engine.hpp
#pragma once

#include "grid_map_5x5.hpp"
#include <functional>

namespace gonxun {
namespace grid_5x5 {

/**
 * @brief 向量计算器
 * 
 * @details 核心向量计算模块
 *          计算公式：vector = target - current
 */
class VectorCalculator {
public:
    /**
     * @brief 计算移动向量
     * @param current 当前位置
     * @param target 目标位置
     * @return MoveVector 移动向量
     */
    static MoveVector calculate(const GridPosition& current, 
                                const GridPosition& target) {
        return MoveVector(target.x - current.x, target.y - current.y);
    }
    
    /**
     * @brief 反向计算（从目标回到当前位置）
     */
    static MoveVector calculateReverse(const GridPosition& current,
                                       const GridPosition& target) {
        return calculate(target, current);
    }
};

/**
 * @brief 网格决策引擎
 * 
 * @details 核心决策模块，生成完整的移动决策
 */
class GridDecisionEngine {
public:
    /**
     * @brief 生成移动决策
     * @param current 当前位置
     * @param target 目标位置
     * @return MoveDecision 完整决策对象
     */
    static MoveDecision makeDecision(const GridPosition& current,
                                     const GridPosition& target) {
        MoveDecision decision;
        decision.current = current;
        decision.target = target;
        decision.vector = VectorCalculator::calculate(current, target);
        decision.description = generateDescription(decision.vector);
        return decision;
    }
    
    /**
     * @brief 批量决策生成（路径规划）
     * @param waypoints 途经点列表
     * @return std::vector<MoveDecision> 决策序列
     */
    static std::vector<MoveDecision> planPath(
        const std::vector<GridPosition>& waypoints) {
        
        std::vector<MoveDecision> decisions;
        if (waypoints.size() < 2) return decisions;
        
        for (size_t i = 1; i < waypoints.size(); ++i) {
            decisions.push_back(
                makeDecision(waypoints[i-1], waypoints[i])
            );
        }
        return decisions;
    }
    
private:
    /**
     * @brief 生成移动描述
     */
    static std::string generateDescription(const MoveVector& vec) {
        return vec.fullDescription();
    }
};

} // namespace grid_5x5
} // namespace gonxun
```

```cpp /home/pldx/Desktop/gonxun/core/src/grid5_path_planner.cpp
Path5Decision Grid5PathPlanner::plan(Grid5Coord current, 
                                     Grid5Coord goal, 
                                     int current_angle,
                                     bool prioritize_x) {
    Path5Decision result;
    result.start = current;
    result.goal = goal;
    result.current_angle = current_angle;
    result.success = false;
    
    if (!isValidCoord(current)) {
        result.error_message = "无效的起点坐标";
        return result;
    }
    
    if (!isValidCoord(goal)) {
        result.error_message = "无效的终点坐标";
        return result;
    }
    
    if (current_angle != 0 && current_angle != 90 && 
        current_angle != 180 && current_angle != 270) {
        result.error_message = "无效的陀螺仪角度（必须为0/90/180/270）";
        return result;
    }
    
    result.vector = calculateVector(current, goal);
    
    if (current == goal) {
        result.success = true;
        result.error_message = "起点和终点相同，无需移动";
        return result;
    }
    
    std::vector<Move5Command> commands;
    int current_angle_state = current_angle;
    
    if (prioritize_x) {
        if (result.vector.dx > 0) {
            int target_angle = 0;
            int turn = normalizeAngle(target_angle - current_angle_state);
            Move5Command cmd;
            cmd.turn_angle = turn;
            cmd.target_angle = target_angle;
            cmd.dx = result.vector.dx;
            cmd.dy = 0;
            cmd.steps = result.vector.dx;

            cmd.turn_angle = turn;
            cmd.target_angle = target_angle;

            cmd.turn_angle = turn;

Move5Vector Grid5PathPlanner::calculateVector(Grid5Coord from, Grid5Coord to) {
    Move5Vector vec;
    vec.dx = to.x - from.x;
    vec.dy = to.y - from.y;
    return vec;
}

int Grid5PathPlanner::vectorToAngle(int dx, int dy) {
    if (dx > 0 && dy == 0) return 0;
    if (dx == 0 && dy > 0) return 90;
    if (dx < 0 && dy == 0) return 180;
    if (dx == 0 && dy < 0) return 270;
    return -1;
}

int Grid5PathPlanner::normalizeAngle(int angle) {
    while (angle > 180) {
        angle -= 360;
    }
    while (angle < -180) {
        angle += 360;
    }
    return angle;
}

std::string Grid5PathPlanner::angleToDirectionName(int angle) {
    switch (angle) {
        case 0:   return "左";
        case 90:  return "下";
        case 180: return "右";
        case 270: return "上";
        default:  return "未知";
    }
}

bool Grid5PathPlanner::isValidCoord(Grid5Coord coord) {
    return coord.x >= 0 && coord.x <= 4 && coord.y >= 0 && coord.y <= 4;
}

void Grid5PathPlanner::printDecision(const Path5Decision& decision) {
    std::cout << "====== 路径决策结果 ======" << std::endl;
    std::cout << "起点: (" << decision.start.x << ", " << decision.start.y << ")" << std::endl;
    std::cout << "终点: (" << decision.goal.x << ", " << decision.goal.y << ")" << std::endl;
    std::cout << "向量: (" << decision.vector.dx << ", " << decision.vector.dy << ")" << std::endl;
    std::cout << "初始角度: " << decision.current_angle << "°" << std::endl;
    
    if (!decision.success) {
        std::cout << "状态: 规划失败" << std::endl;
        std::cout << "错误: " << decision.error_message << std::endl;
        return;
    }
    
    std::cout << "状态: 规划成功" << std::endl;
    std::cout << "移动指令序列:" << std::endl;
    
    for (size_t i = 0; i < decision.commands.size(); ++i) {
        const auto& cmd = decision.commands[i];
        std::cout << "  步骤" << (i + 1) << ": ";
        if (cmd.turn_angle != 0) {
            std::cout << "转向" << cmd.turn_angle << "° → ";
        }
        std::cout << "向" << cmd.direction_name << "移动" << cmd.steps << "格" << std::endl;
    }
    std::cout << "==========================" << std::endl;
}
```
